## [2.0.0] - 2026-11-23

### Added

- The rules `RequireAbstractOrFinal` and `ReadonlyClass`.
- A documentation site at https://phpmath.github.io/coding-standard/.

### Changed

- Requires PHP 8.4 or newer and Doctrine Coding Standard 14.
- Strict types, native types, used and sorted imports are listed explicitly in the ruleset.
- Exception classes keep the `Exception` suffix.

Earlier versions are described on the [releases page](https://github.com/phpmath/coding-standard/releases).
